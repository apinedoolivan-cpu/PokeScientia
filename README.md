# PokéScientia

[Español](#español) · [English](#english)

## Español

Una plataforma personal y bilingüe (español / inglés) de conocimiento Pokémon, ambientada como una academia
clásica de ciencias naturales.

- **El Archivo**: una Pokédex con todas las generaciones, con una vista competitiva por defecto.
- **La Sala de Estrategia**: creación y análisis de equipos centrados en dobles oficiales (VGC).
- **El Laboratorio de Animación**: un escenario de combate 2D animado para explorar la animación web.
- **Más adelante**: calculadora de daño, sets más usados, tendencias, cuentas con sincronización y un asistente de IA.

Cada sala de la academia la presenta un Pokémon residente.

### Estado

Fase de planificación. Todavía no hay código de la aplicación. La visión, los requisitos y las decisiones

## English

A personal, bilingual (Spanish / English) Pokémon knowledge platform, styled as a classical academy of
natural science.

- **The Archive**: a Pokédex covering every generation, with a competitive view by default.
- **The Strategy Hall**: team building and analysis focused on official doubles (VGC).
- **The Animation Lab**: an animated 2D battle stage for exploring web animation.
- **Later**: damage calculator, common sets, trends, accounts with sync, and an AI assistant.

Each hall of the academy is introduced by a resident Pokémon.

### Status

Planning phase. No application code yet. See [`docs/`](docs/) for the vision, requirements and decisions.

### Tech (planned)

Angular and TypeScript · `@angular/localize` · GSAP · PixiJS · local-first storage · Go backend (later).
Built only with free and open-source tools and data.
