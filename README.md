# PokéScientia

A personal, bilingual (Spanish / English) Pokémon knowledge platform, styled as a classical academy of
natural science.

- **The Archive** — a Pokédex covering every generation, with a competitive view by default.
- **The Strategy Hall** — team building and analysis focused on official doubles (VGC).
- **The Animation Lab** — an animated 2D battle stage for exploring web animation.
- **Later** — damage calculator, usage trends, accounts with sync, and an AI assistant.

Each section of the academy is introduced by a resident Pokémon.

## Status

Planning phase. No application code yet. See [`docs/`](docs/) for the vision, requirements and decisions.

## Tech (planned)

Angular and TypeScript · `@angular/localize` · GSAP · PixiJS · local-first storage · Go backend (later).
Built only with free and open-source tools and data.
