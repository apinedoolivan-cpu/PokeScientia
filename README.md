# PokéScientia
Pokescientia is a comprehensive Pokémon web platform focused on knowledge, competitive analysis, team building, and AI-powered tools. Built with Angular 21+ and TypeScript, it will feature a Pokédex, detailed Pokémon data, competitive resources, team analysis tools, and an interactive 2D battle simulator with animated Pokémon and move effects. Its core innovation will be an AI agent capable of dynamically researching Pokémon-related information, analyzing teams and battle scenarios, identifying competitive trends, and generating data-driven strategic recommendations using relevant tools and up-to-date information. The goal is to combine a rich knowledge base, interactive visual experiences, and intelligent analysis into a single platform for Pokémon enthusiasts and competitive players.
